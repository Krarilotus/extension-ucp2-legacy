# ucp2-legacy

این افزونه قابلیت‌های آشنای UCP2 را دوباره در دسترس قرار می‌دهد. تقریباً همهٔ قابلیت‌های منتشرشده در UCP2 به این چارچوب جدید مودسازی منتقل شده‌اند. برای دیدن نمای کلی قابلیت‌ها، بخش Releases مخزن UCP2 در GitHub را ببینید.

## روش استفاده

با فعال‌کردن این افزونه، همهٔ قابلیت‌ها به‌طور پیش‌فرض خاموش هستند. برای استفاده از تنظیمات پیش‌فرض UCP2، افزونهٔ «UCP2 legacy defaults» را فعال کنید. در این صورت UCP2 Legacy به‌عنوان وابستگی فعال خواهد شد.
