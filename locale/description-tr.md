# ucp2-legacy

Bu uzantı, UCP2’den tanıdığınız özellikleri yeniden sunar. UCP2’de yayımlanan özelliklerin neredeyse tamamı bu yeni mod sistemine taşınmıştır. Genel bir bakış için UCP2 GitHub deposunun Releases bölümüne bakın.

## Kullanım

Bu uzantıyı etkinleştirdiğinizde tüm özellikler varsayılan olarak kapalıdır. UCP2 ile gelen varsayılan ayarları kullanmak için “UCP2 legacy defaults” uzantısını etkinleştirin. UCP2 Legacy daha sonra bağımlılık olarak etkinleştirilir.
