# ucp2-legacy

Ez a bővítmény visszahozza az UCP2-ből már ismerős funkciókat. Az UCP2-ben megjelent szinte minden funkció átkerült az új modrendszerbe. Áttekintésük az UCP2 GitHub-forráskódtárának Releases részében található.

## Használat

A bővítmény bekapcsolásakor minden funkció alapértelmezetten ki van kapcsolva. Az UCP2-höz adott alapbeállítások használatához kapcsold be az „UCP2 legacy defaults” bővítményt. Ekkor az UCP2 Legacy függőségként automatikusan bekapcsolódik.
