# ucp2-legacy

Это расширение возвращает знакомые возможности UCP2. Почти все функции, выпущенные в UCP2, перенесены в новую систему модификаций. Их обзор доступен в разделе Releases репозитория UCP2 на GitHub.

## Использование

При включении этого расширения все функции по умолчанию выключены. Чтобы использовать стандартные настройки UCP2, включите расширение «UCP2 legacy defaults». Тогда UCP2 Legacy будет включено как зависимость.
