# ucp2-legacy

Cette extension permet de retrouver les fonctions d’UCP2 que vous connaissez peut-être déjà. Presque toutes les fonctions publiées dans UCP2 ont été portées vers ce nouveau système de mods. Consultez les versions publiées dans le dépôt GitHub d’UCP2 pour en avoir un aperçu.

## Utilisation

À l’activation de cette extension, toutes les fonctions sont désactivées par défaut. Pour utiliser les réglages par défaut fournis avec UCP2, activez l’extension « UCP2 legacy defaults ». UCP2 Legacy sera alors activé en tant que dépendance.
