# ucp2-legacy

Esta extensión permite recuperar las funciones de UCP2 que quizá ya conozcas. Casi todas las funciones publicadas en UCP2 se han adaptado a este nuevo sistema de mods. Puedes consultar un resumen en la sección Releases del repositorio de UCP2 en GitHub.

## Uso

Al activar esta extensión, todas las funciones están desactivadas por defecto. Para utilizar los ajustes predeterminados de UCP2, activa la extensión «UCP2 legacy defaults». UCP2 Legacy se activará entonces como dependencia.
